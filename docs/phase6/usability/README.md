# Usability evaluation kit (Phase 6)

| File | What it is |
|---|---|
| `session-pack.html` | Print this (A4). Facilitator's guide, participant information and consent, task sheet, observation sheet and the SUS questionnaire |
| `files/` | The files participants use: a tender document, an altered copy of it, and a bid |
| `results.csv` | Empty template: one row per participant, filled in from the observation sheet and questionnaire |
| `score.py` | Scores the sessions: SUS per participant, the mean with its adjective rating, and task success rates. Writes `results.md` |

Only real sessions are recorded here; the template has no example rows.

Before running sessions, check whether ZCAS University needs ethics approval for user testing, and adjust the
withdrawal date on the consent form (currently 30 November 2026) if needed.
